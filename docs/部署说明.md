# 普通 Git 部署

这版采用服务器自行拉取代码的方式，不使用压缩包，也不需要授权 Mac 登录服务器。

## 首次部署

源码仓库公开：https://github.com/Vergil-coder/vergil-site 。服务器通过 HTTPS 拉取，无需 GitHub 登录或 SSH 部署密钥。

服务器需有 Git、Node.js 22.12 或以上、npm 和现有 Nginx。在服务器终端执行：

```bash
git clone https://github.com/Vergil-coder/vergil-site.git /opt/vergil
cd /opt/vergil
npm ci
npm run build
```

Nginx 站点目录为 /opt/vergil/dist。配置示例在 deploy/vergil.me.conf；如已有其他文件配置 vergil.me，先核对，避免重复。修改个人站配置前先备份，不修改 Pactime、Mellowfin 或公司站点。

确认没有重复站点后，把该个人站配置放到 /etc/nginx/conf.d/vergil.me.conf，再执行：

```bash
nginx -t && systemctl reload nginx
```

已有 vergil.me 独立证书时，可用 deploy/vergil.me.https.conf；证书文件必须确实存在。没有根域名证书时，沿用之前成功的 Certbot DNS 验证方式另行申请；不要使用只包含 App 子域名的证书。

## 以后更新

本地提交并推送代码，然后在服务器执行：

```bash
cd /opt/vergil
npm run update
```

等同于 git pull --ff-only、npm ci、npm run build。服务器有未提交修改时会停止，不强制覆盖。静态内容更新后不需要 reload Nginx。
